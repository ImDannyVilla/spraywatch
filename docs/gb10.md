# Running SprayWatch on the GB10

SprayWatch uses the model NemoClaw runs: Qwen3.6 in NemoClaw's vLLM container, `nemoclaw-vllm`, on port 8000. Nothing else needs a GPU. The watcher, the check and the page run on the host with Python 3.12 and poppler.

## Once

```bash
sudo apt-get install -y poppler-utils          # pdftotext; already on the GB10
git clone <repo> ~/spraywatch && cd ~/spraywatch
sh scripts/install-hooks.sh
make verify
sh scripts/fetch_labels.sh                      # the real demo label, into state/labels/
```

**The model.** Put the model settings in an env file outside the repo, readable only by you. The key is NemoClaw's vLLM key (`docker inspect nemoclaw-vllm --format '{{json .Args}}'` shows it):

```bash
mkdir -p ~/spraywatch-input && chmod 700 ~/spraywatch-input
cat > ~/spraywatch-input/model.env <<'ENV'
MODEL_URL=http://127.0.0.1:8000/v1
MODEL_NAME=nvidia/Qwen3.6-35B-A3B-NVFP4
MODEL_API_KEY=<the key>
ENV
chmod 600 ~/spraywatch-input/model.env
python3 scripts/read_label.py state/labels/captan-80-df.pdf --env ~/spraywatch-input/model.env
```

That last line is the live check: it should print 41 of 41 facts verified.

**Slack.** The bot needs the `chat:write` scope (and `chat:write.public` to post without an invite). The token comes from the password manager and never goes in git:

```bash
export SLACK_BOT_TOKEN=...    # the bot token
export SLACK_CHANNEL=...      # the channel's ID
```

Without them, cards wait and go out on the first pass after Slack is set. `SPRAYWATCH_SLACK=print` prints them instead.

## Run it

Three processes; `nohup` or a `tmux` window each:

```bash
export SPRAYWATCH_MODEL_ENV=~/spraywatch-input/model.env
python3 agent/watch.py > state/watch.log 2>&1 &      # the inbox, then a check, every 10 s
python3 evidence/server.py > state/page.log 2>&1 &   # http://127.0.0.1:8091/
```

The watcher's check posts the morning digest on its first pass after `morning_time` in `policy/policy.json`. To run the check from cron instead of the watcher, for the morning card on a box that doesn't run the watcher:

```bash
30 6 * * * cd ~/spraywatch && SLACK_BOT_TOKEN=... SLACK_CHANNEL=... python3 agent/check.py --morning
```

Drop files in `state/inbox/`: label PDFs or photos, `blocks.csv`, `sprays*.csv`, `harvests*.csv`, `crew*.csv`. The shapes are in [the contract](../contracts/README.md#the-inbox).

| Variable | Default | What |
| --- | --- | --- |
| `SPRAYWATCH_INBOX` | `state/inbox` | The folder the watcher reads |
| `SPRAYWATCH_DB` | `state/spraywatch.db` | SQLite |
| `SPRAYWATCH_QUEUE` | `state/queue` | Approved schedule changes |
| `SPRAYWATCH_POLICY` | `policy/policy.json` | Approvers, times, card templates |
| `SPRAYWATCH_MODEL_ENV` | unset | The model env file |
| `SPRAYWATCH_FAKE_REPLIES` | unset | A folder of saved replies instead of the model |
| `SPRAYWATCH_BASE_URL` | `http://127.0.0.1:8091` | The link on every card |
| `PAGE_PORT` | `8091` | The local page's port |
| `POLL_SECONDS` | `10` | The watcher's interval |

## The demo

```bash
python3 scripts/demo.py --live --no-confirm     # Qwen reads the labels; confirm them on the page
SPRAYWATCH_DB=state/demo/spraywatch.db SPRAYWATCH_INBOX=state/demo/inbox SPRAYWATCH_QUEUE=state/demo/queue \
  SPRAYWATCH_SLACK=print python3 evidence/server.py
```

Then, on the page: confirm the three labels (the proof is the highlighted label line), open the Block 4 harvest alert, approve the new date, and print the Block 5 posting. To show "whenever a new spray is logged", use **Log a spray** for Block 4 grapes with Demothrin 2EC: the harvest alert for its 14 days is raised and carded at once.

## Inside a NemoClaw sandbox

SprayWatch runs in its own sandbox, `spraywatch`, on NemoClaw's Qwen. [`scripts/nemoclaw/onboard.sh`](../scripts/nemoclaw/onboard.sh) creates it:

| What | How |
| --- | --- |
| Model | The running `nemoclaw-vllm`, attached as an existing server (`NEMOCLAW_PROVIDER=vllm`); not restarted. Inside, `http://host.openshell.internal:8000/v1` with NemoClaw's placeholder token |
| Policy | Restricted tier with no optional presets, plus [`spraywatch-slack-post`](../scripts/nemoclaw/spraywatch-slack-post.yaml): Python may POST `chat.postMessage` to slack.com and nothing else on Slack. The stock `slack` preset is for OpenClaw's Socket Mode, and OpenShell refuses a second rule for `slack.com:443` while it's on |
| Mounts | Read-only: the repo at `/sandbox/spraywatch/app`, the farm inbox at `/sandbox/spraywatch/inbox`. SQLite and the queue live in `/sandbox/spraywatch-state` |
| Slack | The bot token is a gateway credential, `SPRAYWATCH_SLACK_BOT_TOKEN`; the sandbox sees only a placeholder. No Socket Mode and no OpenClaw Slack channel. Gateway credentials attach to every sandbox built after they're added |
| PDFs | The sandbox has no poppler. On the host, `scripts/pdf_pages.py --watch` writes each PDF's text next to it, stamped with the PDF's SHA-256 |

```bash
mkdir -p ~/spraywatch-input && chmod 700 ~/spraywatch-input
$EDITOR ~/spraywatch-input/slack.env      # SPRAYWATCH_SLACK_BOT_TOKEN=xoxb-...  and  SLACK_CHANNEL=C...
chmod 600 ~/spraywatch-input/slack.env
sh scripts/nemoclaw/onboard.sh
nemoclaw spraywatch exec --no-tty -- sh /sandbox/spraywatch/app/scripts/nemoclaw/start.sh
openshell forward start --background 8091 spraywatch                 # the page on http://127.0.0.1:8091/
nohup python3 scripts/pdf_pages.py ~/spraywatch-farm/inbox --watch > ~/spraywatch-farm/pdf_pages.log 2>&1 &
```

Drop label PDFs and the CSVs in `~/spraywatch-farm/inbox/`. Approved changes are in the sandbox; copy them out with `nemoclaw spraywatch download /sandbox/spraywatch-state/queue ~/spraywatch-farm/queue`.
